三步开始使用

当前为内测版，首次配置需要 Claude Code Router（CCR）以及自己的 DeepSeek、Qwen API Key。

安装 CCR

安装并启动 Claude Code Router，在 API Keys 页面创建一个本地 Client Key。

安装 Friend Router

下载 DMG，将 App 拖入 Applications。首次请右键 App，选择“打开”。

填写密钥并连接

在右上角菜单选择“设置…”，填写 DeepSeek、Qwen 与 CCR Client Key，再点击“安装并连接 Codex”。

内测提醒：当前安装包采用内测签名，macOS 可能提示无法验证开发者。请仅从本页面下载，并核对下面的 SHA-256。
