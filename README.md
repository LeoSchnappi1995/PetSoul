# Petinder 社交软件原型

一个手机优先的宠物社交 Web 原型，围绕三个核心 Tab：

- Petinder：人和宠物合影卡片，左滑跳过、右滑约一起遛宠。
- Pet 星球：地图上发现遛狗圈、遛猫圈、同城品种圈。
- 消息：好友之间快速发送「遛了么」「喂了么」「摸了么」轰炸。

## 本地启动

```bash
npm install
npm run dev
```

打开：

```text
http://localhost:5178
```

## 当前功能

- 三 Tab 底部导航
- Petinder 卡片队列、按钮滑动、拖拽滑动、滑动印章反馈
- 狗、猫、蜥蜴、乌龟人宠合影卡片
- 上海市区卡通地图、同城品种星球入口、圈子头像集合
- 消息列表与「遛了么」小狗怒视轰炸弹窗
- 移动端优先的响应式界面
